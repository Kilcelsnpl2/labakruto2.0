## Коротко о проекте
ALGOL 60 — язык, который проиграл коммерцию, но победил в влиянии. В 1965–1970 годах он стал стандартом для описания синтаксиса других языков (BNF), но почти никто не писал на нём программы. Эта страница — реклама вымышленных курсов по ALGOL 60 в стиле научного журнала того времени: серьёзный тон, ироничное название, лектор — Джон Бэкус, создатель Fortran, который одновременно описал ALGOL 60.
