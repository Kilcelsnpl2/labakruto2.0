# Кто ведёт курс

## Назначение
Посетитель должен понять, кто будет вести курс и почему он компетентен.

## Содержание
- Имя: Джон Бэкус (John Backus)
- Регалии: создатель языка Fortran, один из разработчиков BNF (формы Бэкуса-Наура), участник комитета по созданию ALGOL 60.
- Вымышленная биография: «Более 20 лет опыта работы с языками программирования. Создатель первого высокоуровневого языка (Fortran). Один из авторов формального описания синтаксиса ALGOL 60 (BNF). Участник международных конференций по языкам программирования.»

## Связь с объектом
Джон Бэкус — создатель Fortran, который одновременно описал ALGOL 60. Это идеальная ирония: «человек, который создал конкурента, но описал его».
